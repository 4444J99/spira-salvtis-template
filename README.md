# SPIRA SALVTIS

**A Sales and Wellness Funnel Template**

*Spira Salvtis* (The Spiral of Wellness) is a deployable digital storefront and knowledge graph template designed for health and wellness practitioners. 

It features two core modalities:
1. **The Hub (Spira):** A 3D interactive knowledge graph (powered by Three.js and golden-angle spiral physics) where users visually explore the practitioner's philosophy.
2. **The Spokes (Vortex):** Targeted, linear conversion funnels attached to specific nodes. These funnels use dynamic routing and API-integrated quizzes to qualify leads and drive high-ticket sales.

## Repository Architecture

This template is designed around an "Ideal Forms" 3-tier architecture to securely sequester private IP from the public portfolio presentation.

1. **The Engine (This Repository)**
   - **Nature:** Public Portfolio Template
   - **Contents:** UI components, Three.js spiral physics, generic layouts, and public configuration.

2. **The Corpus / Operation**
   - **Nature:** Strictly Private
   - **Contents:** Client transcripts, financial agreements, raw research, and decision logs.

3. **The Live Deployment (Content Injector)**
   - **Nature:** Private or Public
   - **Contents:** Real markdown content, environment variables, and live analytics tracking codes.
